    荣耀 X16 锐龙版（2024）运行 Linux 问题和修复

    荣耀 X16 锐龙版（2024，R5-7640HS）装上 CachyOS 后出现两类问题：合盖睡眠后唤醒需 8 秒以上甚至睡死，以及 HDMI 外接显示器画面灰白发亮、KDE 中切换 RGB 与 YCbCr 色彩范围均无效。前者源于荣耀 BIOS 阉割了 S3、只剩 Modern Standby，通过在 UAFB 中打开 AMD RAID Mode 恢复正常秒唤醒；后者经排查无果，改用 USB-C 扩展坞走 DisplayPort 输出后色彩正常。作者认为该机 BIOS 精简过多、Linux 下问题难根治，不推荐 Linux 用户购买，但在 Windows 下表现良好。

    Love Love School Days 在 Linux 下游戏汉化补丁安装使用

    Love Love School Days 是一款 2023 年发行的 Unity 游戏，Steam 上无官方中文，B 站 UP 主提供了基于 BepInEx 和 Reipatcher 的汉化补丁。在 Fedora 43 与 Bazzite 43 上用 Proton 运行并覆盖补丁后游戏仍为英文，原因是 Proton/Wine 默认不加载游戏目录内的 dll，导致 UnityDoorstop 无法启动 BepInEx。解决办法是用 Protontricks 选中该游戏、进入 Wine 配置程序的“函数库”页，新增 winhttp 函数库顶替并保存退出，之后游戏即显示中文。也可在补丁已安装的前提下直接给 Steam 添加启动参数 WINEDLLOVERRIDES="winhttp=n,b" %command%，效果与前者一致。

    Fedora Silverblue 安装记录和不可变 Linux 个人杂谈

    从 Steam Deck 换用基于 Fedora Silverblue 的 Bazzite 后，作者重新体验了不可变 Linux，并记录了 Fedora Silverblue 的安装流程：官网或国内镜像站下载 ISO，用 Ventoy、Rufus 或 Fedora Media Writer 制作启动盘，经传统 Anaconda 安装器部署后首次开机执行 rpm-ostree update 并重启。配置上建议启用 Flathub，通过 Flatpak 安装应用，按需添加 GNOME 扩展，必要时才用 rpm-ostree 叠加软件包，并可借助 Distrobox 运行其他发行版应用。作者认为，采用 A/B 分区与只读系统、支持原子更新和回滚的不可变发行版，对不想折腾系统的大众桌面用户更安全合适，正逐渐成为 Linux 桌面的未来主流形态。

    国内外主流对象存储价格对比

    在 CachyOS Handheld 下恢复 Steam Input 中文输入

    在 CachyOS Handheld（基于 Arch Linux 的 SteamOS 仿制发行版）上，游戏桌面默认缺失输入法支持，导致 Steam Input 中文输入无法使用。解决方式是先用 paru 安装 ibus、ibus-pinyin 与 ibus-anthy，再编辑 /usr/share/gamescope-session-plus/gamescope-session-plus，把 ibus-daemon 的启动参数改为使用 /usr/lib/kimpanel-ibus-panel 面板，重启后在游戏桌面添加中文键盘。若不降级 libxkbcommon，候选词会变成数字，因此需用 downgrade 将 libxkbcommon 回退到 1.11.0 并加入 IgnorePkg，重启即可正常输入中文。

    Waline-Mini 部署体验：基于 Rust 的 Waline 评论系统？

    Waline-Mini 是用 Rust 重写的 Waline 评论系统，由 jQiue 开发，官方称内存占用仅为 Node.js 版本的 1/25。通过 Zeabur 以 Docker 镜像方式部署，配置 DATABASE_URL、JWT_TOKEN、SITE_NAME、SITE_URL 等环境变量，并用 SQLite 做数据持久化，访问 /ui 注册的首个账号即为管理员。部署完成后台界面与 Waline 还原度接近 100%，实测平均内存占用约 3.48MB，验证了其极低的资源消耗。整体适合希望低成本自托管评论系统的用户尝试。
